1. Làm tiếp sau khi hết token hoặc mở chat mới
Resume the project. Read AGENTS.md, SPEC.md, PLAN.md, DECISIONS.md and 
CHANGELOG.md. Tell me in Vietnamese in 5 lines: which tasks are done, which one is 
in progress, and what the next task is. Then do ONLY the next task and stop.

2. Khi gặp lỗi
Bug: [mô tả ngắn hoặc dán nguyên thông báo lỗi].
Act as Builder. First find the cause and tell me in Vietnamese. Write a test that 
reproduces it, then make the smallest possible fix, only in the files related to the 
failing task. Do not rewrite other code. Log it in CHANGELOG.md and commit.

3. Khi muốn thêm hoặc đổi tính năng
Change request: [bạn muốn gì].
Act as Planner only. Tell me which R items in SPEC.md this affects and which files 
in the code. Propose the SPEC.md and PLAN.md changes and wait for my OK. Do not 
write code yet.

4. Kiểm tra chạy lệnh 
git status
git log -1

5. Hết token ở dòng chat tài khoản
Token is running low. Update PLAN.md, DECISIONS.md and CHANGELOG.md so they 
exactly match the current state of the code. For the task in progress, add a "Where 
I stopped" note: what is done, what is left, and the exact next step. Then commit.

6. Các phần chú ý khi chuyển sang tài khoản khác
"Resume the project": đọc file, báo cáo, làm task kế tiếp.
"Bug": báo lỗi, sửa nhỏ nhất.
"Change request": đổi yêu cầu thì sửa SPEC.md trước.

7. Những điều chú ý nếu bị ngắt token giữa chừng
    1. Đừng cho nó làm cả phase trong một lượt.
    AGENTS.md đã bắt nó làm từng task, nhưng một phase gồm nhiều task. 
    Bạn dặn: "làm đúng task T1 rồi dừng". Phase nào bị ngắt giữa chừng thì thứ mất chỉ 
    là task đang làm, các task trước đã done và đã commit.

    2. Nếu nó bị ngắt giữa task:

    Code có thể đã viết một nửa. Mở Source Control (biểu tượng nhánh ở thanh trái) 
    xem file nào đang thay đổi mà chưa commit.
    Đổi tài khoản hoặc chờ có token, rồi mở chat mới và dán câu "Resume the project".
    Nó thấy task ở trạng thái doing và thấy file sửa dở. Bạn bảo thêm: 
    Compare PLAN.md, git status and the code. Tell me what is finished 
    and what is half-done in the current task. Then finish it.

    3. Nếu bạn thấy code dở dang và rối:
    
    Đây là lúc git phát huy tác dụng. Bạn bảo nó: "Discard the 
    uncommitted changes of the current task and redo it from the last commit." 
    Làm lại từ đầu task nhỏ thường nhanh hơn vá code dở. Mình không nên đoán 
    lệnh git chính xác cho bạn, cứ để agent chạy và bạn xem nó báo gì trước khi đồng ý.

    4. Phòng trước, tốn rất ít công:

    Khi thấy token còn ít, gửi câu "Token is running low..." (ở mục 5) để nó 
    ghi Where I stopped và commit. Đừng đợi tới khi nó tự ngắt.
    Yêu cầu nó commit sau mỗi task, không đợi hết phase. Bạn cứ dặn 
    "commit sau mỗi task" trong prompt giao việc nếu thấy nó quên.
    Giữ task nhỏ. Task càng nhỏ thì khi bị ngắt càng ít mất.
